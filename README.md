# Kite Outdoor Gear — Complete Website

HTML + CSS + vanilla JavaScript conversion of the supplied Stitch screens.

## Pages
- index.html — Coastal Winds home
- home-2.html — Mountain Pro home
- products.html — Product catalog
- product-zephyr-pro.html — Zephyr Pro product
- beach-gear.html — Outdoor beach gear
- events.html — Events & festivals
- buying-guide.html — Buying guide
- contact.html — Gear support/contact

## Global functionality
- Light/dark theme toggle
- RTL/LTR toggle
- Theme and direction persist using localStorage
- Cross-page navigation
- Responsive behavior
- Same-page smooth scrolling
- Basic client-side form validation and feedback

## Run
Open index.html, or:
python -m http.server 5500
Then visit http://localhost:5500
